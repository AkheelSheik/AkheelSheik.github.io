Hitachi Global Air Power

My role as Engnieering Intern and then Graduate Electrical and Controls engineer in Hitachi Global Air Power involved various tasks. From assisting the engineer in testing new technologies, developing visuals for data from testing and also gaining in experience in engineering tools such as NX and SAP ECTR.

Skills

  • Power BI
  • Data Analysis
  • SAP ECTR
  • NX
  • AutoCAD

Projects

Testing Fan VSD fan in test cell

The major action that I took was reading the software and hardware instructions of an inverter so that I could understand all the variables used to configure the software of the inverter. I also had to learn how to implement a PID controller in the inverter. Furthermore, I did wiring to connect toggle switches for the test cell fan inverter.

Utilizing NX and AutoCAD

I used SAP engineering control center to make changes to existing products. This involved using NX for update switchgear panels and using AutoCAD to update wiring diagrams. I mostly worked in the assembly mode of NX constraining parts to each other and the back panel however I also model parts although there were mostly reference models.

Testing Controller

I created Controller, MODBUS RTU and MODBUS TCP/IP manuals. I also performed control system testing on air compressor controller, identifying faults through systematic troubleshooting and providing guidance on implementing corrective actions.

Data Visualization

Got experience in generating beautiful reports using Power BI. This involves taking from data combining two sources of data into a paginated power bi report. I also got experience building a DASH app for data analysis. The purpose of the application was to be able trend data interactively and compare it with other machines out in the field.
